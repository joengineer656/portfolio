## Why it matters

Almost every robot I build has at least one PID loop. Tuning by guessing works, slowly. Tuning in a fixed order works every time.

## The order

1. Set I and D to zero.
2. Raise P until the system oscillates, then halve it.
3. Add D until the overshoot is gone.
4. Add a little I to remove the last steady error.
