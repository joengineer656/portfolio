## The question

How long can one coin cell run a sensor that sends data every minute?

## What I built

A small board with a low-power radio, a sleep-first firmware loop and a vibration sensor that wakes it up.

## What happened

Eight months on one cell. Range is good in the open and poor behind concrete walls.
