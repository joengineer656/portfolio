## The idea
The idea of this board is to make a fully featured gateway (SBC Board) in PICO-ITX size or smaller compatible with Raspberry Pi shields
And make it fully open source
## Things I need to add
- RK3576 CPU
- LPDDR5 Up to 16GByte
- RP2350A MCU
- 2 RJ-45 connector (with AVB/TSN Support)
- 2 Stack USB A Host
- UFS/eMMC connector for [external board from Radxa](https://radxa.com/products/accessories/ufs-module/)
- Key E connector for wireless boards such as (**Intel AX200 / AX210**, **MediaTek MT7921 / MT7922 / MT7925**, **RAK5166/RAK5167**)
- 40pin GPIO from RK3576 & 20pin from RP2350A
- Key M Connector for Nvme SSD
- MIPI (CSI, DCI) for cameras and display
- full size HDMI
- 2 USB-C (RK3576 with OTG&DP, RP2350A)
- uSD Card soket
- Boot from UFS/eMMC, Nvme SSD, uSD card
- DC Jack for Power Up to 25v
